## 2. 模型

### 2.1 玩家属性
- 攻击 = (境界攻击 + Σ6槽底子攻击 × 档位倍率 × 品质倍率) × (1 + 0.025 × 词条总数)；生命同理；防御不吃词条折算。
- 暴击期望 = 1 + 暴击率 × (暴伤 − 1)。
- 每条词条折算 2.5%：16 条词条约一半是输出类，输出类单条在蓝/紫的均值约 5%。
- 装备进度假设（balance.py 的 GEAR，等效档位 / 等效品质序号 1白…5橙）：

| 地图 | 第1关 | 第2关 | 第3关 | 第4关 | 第5关 |
|---|---|---|---|---|---|
| 青竹山 | T1 / 1.3 | T1 / 2.0 | T1 / 2.4 | T1 / 2.7 | T1 / 3.0（约全蓝） |
| 雷泽谷 | T1.5 / 2.8 | T1.8 / 2.8 | T2 / 2.9 | T2 / 3.0 | T2 / 3.2 |
| 玄岩洞 | T2.5 / 3.0 | T2.8 / 3.0 | T3 / 3.1 | T3 / 3.2 | T3 / 3.4 |

  依据：每关首通必出蓝+、首领每次必出1件、普通怪4%/只；一张图约18~22件装备，可覆盖6槽并以蓝为主；进入新图时只有一半槽位换成新档。

### 2.2 DPS 模型
```
普攻 DPS   = 攻击 × 1.0 / 0.8秒
技能 DPS_i = 攻击 × 系数_i(等级) × 段数_i × 目标系数_i(n) / [冷却_i(等级) × (1 − 冷却缩减)] × (1 + 流派增伤)
总 DPS     = (普攻 + Σ 4个主动) × 暴击期望 + 护体反震 + 反伤
有效 DPS   = 总 DPS × 输出占比（清怪0.85 / 首领0.80）
```
- 目标系数 n = 同时可打到的敌人数（聚团怪计1、分散怪计0.5，上限6）：弹道=1；贯穿=1+0.5(n−1)×0.85；连锁=1+(Σ衰减序列−1)×0.85；圆/光环=1+(n−1)×min(1,半径/220)×0.85；九霄神雷总伤与人数无关。
- 飞剑诀：追加飞剑期望=概率×段数×0.8；诛仙剑对首领×(1+50%起)。
- 玄罡诀（v2）：
  - **护体反震** = 攻击 × 反震系数 × 每秒受击次数 × 护盾覆盖率（6秒/冷却），不暴击；**吃被反震者防御**（COUNTER_IGNORE_DEF=0）。每秒受击次数：首领战=首领普攻频率；清怪=最多3只近战怪同时贴身的攻击频率；两者都受全局内置间隔0.8秒封顶（≤1.25次/秒）。
  - **反伤** = 首领普攻伤害（减伤前）×（被动反伤 + 护体反伤×护盾覆盖率），上限60%；**吃首领防御**（REFLECT_IGNORE_DEF=0）。清怪阶段不计反伤（偏保守）。
  - v4 核对：v2/v3 的 balance.py 把反伤、反震都并入“有效DPS”，再去打“有效血量=HP/(1−减伤率)”，两者都吃防御，与前端实现一致。v4 起由 constants 开关控制，改成 1 时模型自动按无视防御计算。
  - 金刚不坏爆发 = 6.0×攻击 + 护盾×60%实际吸收×1.5。
  - v1 的“护体护盾期间增伤25%”已删除。
- 敌人有效血量 = HP × 关卡倍率 / (1 − DEF/(DEF+100))。

### 2.3 每关耗时
```
接敌(距离, 敌速) = max(0, 距离 − AUTO_ENGAGE_RANGE_PX 450) / (PLAYER_MOVE_SPEED 220 + 敌速)
4波清怪 = RUN_START_WALK_TIME 1秒 + WAVE_ENTER_WALK_TIME 3秒 × 3
        + Σ_波 [有效血量和 / 有效群体DPS(n) + 接敌(SPAWN_DISTANCE_PX 760, 本波最快敌速) + 本波最大 spawn_delay_s]
首领     = 接敌(BOSS_SPAWN_DISTANCE_PX 560, 首领移速) + 首领有效血量 / 有效单体DPS      ← 与60秒限时同口径
登场+结算 = BOSS_INTRO_TIME 3秒 + RESULT_SHOW_TIME 2秒
本关     = 4波清怪 + 首领 + 登场+结算 + 操作开销60秒（1-1 另加150秒引导）
地图终关 = 另加突破补刷：修为或灵石不够时重复挂机本关（每轮 = 纯击杀耗时×0.85 + 固定节奏），再加60秒突破/切图
```
- v4：上式中带英文名的节奏参数都由 balance.py 从 constants.csv 读取（与前端同名常量一致）；缺任何一个会直接报错退出。补刷时只有击杀部分按 0.85 缩短，行进/接敌/登场/结算不缩短（v3 之前是整轮×0.85）。
- 技能等级按首通+击杀灵石逐关累计，85% 用来给已装配技能“先升最便宜的一级”，并为下次突破预留灵石。
- 主线配置只用当时已拿到的书（新手3本+首通保底；v2 起第5关首通给终极书），在“首领战手动存活 ≥ 首领耗时×1.2 且首领 ≤55秒”的前提下，选 60%群体+40%单体 综合DPS最高的 4主动+1被动。
