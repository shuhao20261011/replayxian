## 2. 模型

### 2.1 玩家属性
- 攻击 = (境界攻击 + Σ6槽底子攻击 × 档位倍率 × 品质倍率) × (1 + 0.025 × 词条总数)；生命同理；防御不吃词条折算。
- 暴击期望 = 1 + 暴击率 × (暴伤 − 1)。
- 每条词条折算 2.5%：16 条词条约一半是输出类，输出类单条在蓝/紫的均值约 5%。
- 装备进度假设（balance.py 的 GEAR，等效档位 / 等效品质序号 1白…5橙）：

| 地图 | 第1关 | 第2关 | 第3关 | 第4关 | 第5关 |
|---|---|---|---|---|---|
| 青竹山 | T1 / 1.3 | T1 / 2.0 | T1 / 2.4 | T1 / 2.7 | T1 / 3.0（约全蓝） |
| 雷泽谷 | T1.5 / 2.8 | T1.8 / 2.8 | T2 / 2.9 | T2 / 3.0 | T2 / 3.2 |
| 玄岩洞 | T2.5 / 3.0 | T2.8 / 3.0 | T3 / 3.1 | T3 / 3.2 | T3 / 3.4 |

  依据：每关首通必出蓝+、首领每次必出1件、普通怪4%/只；一张图约18~22件装备，可覆盖6槽并以蓝为主；进入新图时只有一半槽位换成新档。

### 2.2 DPS 模型
```
普攻 DPS   = 攻击 × 1.0 / 0.8秒
技能 DPS_i = 攻击 × 系数_i(等级) × 段数_i × 目标系数_i(n) / [冷却_i(等级) × (1 − 冷却缩减)] × (1 + 流派增伤)
总 DPS     = (普攻 + Σ 4个主动) × 暴击期望 + 护体反震 + 反伤
有效 DPS   = 总 DPS × 输出占比（清怪0.85 / 首领0.80）
```
- 目标系数 n = 同时可打到的敌人数（聚团怪计1、分散怪计0.5，上限6）：弹道=1；贯穿=1+0.5(n−1)×0.85；连锁=1+(Σ衰减序列−1)×0.85；圆/光环=1+(n−1)×min(1,半径/220)×0.85；九霄神雷总伤与人数无关。
- 飞剑诀：追加飞剑期望=概率×段数×0.8；诛仙剑对首领×(1+50%起)。
- 玄罡诀（v2）：
  - **护体反震** = 攻击 × 反震系数 × 每秒受击次数 × 护盾覆盖率（6秒/冷却），不暴击。每秒受击次数：首领战=首领普攻频率；清怪=最多3只近战怪同时贴身的攻击频率；两者都受全局内置间隔0.8秒封顶（≤1.25次/秒）。
  - **反伤** = 首领普攻伤害（减伤前）×（被动反伤 + 护体反伤×护盾覆盖率），上限60%。
  - 金刚不坏爆发 = 6.0×攻击 + 护盾×60%实际吸收×1.5。
  - v1 的“护体护盾期间增伤25%”已删除。
- 敌人有效血量 = HP × 关卡倍率 / (1 − DEF/(DEF+100))。

### 2.3 每关耗时
```
4波清怪 = Σ_波 [有效血量和 / 有效群体DPS(n) + 行进3秒 + 刷怪错开1.5秒]
首领     = 首领有效血量 / 有效单体DPS + 登场3秒
本关     = 4波清怪 + 首领 + 操作开销60秒（1-1 另加150秒引导）
地图终关 = 另加突破补刷：修为或灵石不够时重复挂机本关（每轮=首通战斗耗时×0.85），再加60秒突破/切图
```
- 技能等级按首通+击杀灵石逐关累计，85% 用来给已装配技能“先升最便宜的一级”，并为下次突破预留灵石。
- 主线配置只用当时已拿到的书（新手3本+首通保底；v2 起第5关首通给终极书），在“首领战手动存活 ≥ 首领耗时×1.2 且首领 ≤55秒”的前提下，选 60%群体+40%单体 综合DPS最高的 4主动+1被动。

### 2.4 生存模型（v2 改为 0.1 秒步长逐帧模拟）
- 普攻与按攻击系数结算的危险攻击按速率持续扣血（×防御减伤，罡风护身减伤按覆盖率折算）。自动模式危险攻击全中（计划：自动不闪避）；手动按闪避80%危险攻击结算期望值。
- 玄岩天坠（true_maxhp）在 15/35/55 秒…离散结算：最大生命×70% 真实伤害，先扣护盾；手动按期望 20% 结算。
- 护盾AI：护体按冷却释放；金刚不坏为天坠预留（预警期间可用就立刻开，否则只在冷却好之前不会撞上下次预警时才开）。
- 输出存活秒数（模拟上限300秒，超过记∞）和最低血量比例。

## 6. 经济、离线与已知局限
- 技能升级：基础技能满级累计 6180 灵石，终极 11130。
- 离线（offline_rewards.csv）= 在线挂机每轮收益 ÷ 130秒 × 60 × 50%，8小时封顶（保持不变）。
- 装备进度和“每条词条 2.5%”是假设，不是掉落模拟；输出占比 0.85/0.80、操作开销 60 秒为经验值，需在试玩包里埋点后回填 balance.py 的 ASSUME。
- 模型未计入护盾强度词条和玄罡核心橙装的护盾爆发，实战中玄罡扛天坠的余量会更大。
- 玄岩天坠（v3 决策）：保留“首通必须手动闪避”。首次遇到天坠预警时由 TUT_07_SKYFALL_DODGE 提示“按空格闪避”（0.3 倍慢放 0.8 秒，不暂停，最多提示3次）。
- 在线自动挂机回退（v3 决策，constants.AUTO_FAIL_RETREAT_COUNT=1）：飞剑/御雷等无护盾配置在 3-4/3-5 自动挂机失败 1 次后，会自动回退到 3-3（或更低的未标记已通关关卡）继续刷，不会在同一关反复死。换配置、升级技能、突破或手动通关后会解除标记，再次尝试高关。
- 主线时长估算不受回退规则影响：主线按“首通”计时，补刷发生在 1-5、2-5，这两关的主线配置都能自动通过。
