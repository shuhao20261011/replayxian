# 《重走修仙路》风格说明 v0.1（样张阶段）

> 状态：风格样张，待用户确认后出正式资源。基准分辨率 1280×720，Godot 4.7.2（Compatibility 渲染器），键鼠操作。
> 所有样张由 `src/` 下 Python 脚本程序化生成（`python3 src/build_all.py` 一键重建），便于改色、改构图后迭代。

## 1. 一句话风格

**宣纸底 + 水墨远山层层晕染 + 浓墨剪影角色 + 朱砂点睛；画面里只有特效、掉落和可交互 UI 是亮的。**

- 背景：3–4 层远山/景物，越远越淡、越近越浓，层间以云雾带留白分隔（水墨「晕染 + 留白」）。
- 角色：纯黑剪影（#1C1E21），不画内部细节，靠轮廓表达动作。主角唯一的颜色是朱砂披帛、发带和剑穗；敌人唯一的颜色是发光的眼睛和裂纹。
- 特效：外层彩色柔光、主色体、白色内核三层，是全画面饱和度最高的元素。
- UI：深墨半透明面板（#1B1D20，约 78% 不透明），金色细描边，标题用宋体粗（Noto Serif SC Bold），数值用黑体（Noto Sans SC）。

## 3. 三张地图的区分要点

| 地图 | 色调 | 天空明度 | 主色（天空 / 主色 / 深色 / 点缀） | 标志性远景 | 敌人眼光色 |
| --- | --- | --- | --- | --- | --- |
| 青竹山 | 青绿淡墨，晴朗薄雾 | 亮 | `#DDE7D9` / `#6E9A82` / `#2E5A48` / `#FBF6E4` | 前景浓墨竹林、中景淡竹、远山亭台、柔和日轮 | 朱红 `#FF5A3C` |
| 雷泽谷 | 靛紫浓墨，雷雨 | 中暗 | `#2C3150` / `#5D6699` / `#1E2138` / `#C9D6FF` | 滚滚乌云、远处落雷、尖峭山峰、水泽倒影、芦苇、枯树、斜雨 | 冰蓝 `#BFD3FF` |
| 玄岩洞 | 玄黑赭红，地火逆光 | 暗（底部亮） | `#1F1614` / `#4A3631` / `#140E0D` / `#E8692F` | 钟乳洞顶、熔岩瀑、熔岩暗河、石笋、地缝火光、火星 | 熔橙 `#FF7A2E` |

区分规则：三张地图共用同一条地平线（y=585）和同一套剪影规则，靠以下三点一眼区分：

1. **色温**：青竹山偏冷绿，雷泽谷偏冷紫，玄岩洞偏暖红。
2. **天空明度**：青竹山亮，雷泽谷中暗，玄岩洞全暗、只有底部发亮。
3. **轮廓语言**：青竹山是竖直竹竿和圆缓山形，雷泽谷是尖峰和折线闪电，玄岩洞是倒挂钟乳和发光竖线（熔岩瀑）。

可读性要求：角色行走带（y 约 420–585）的背后必须比剪影亮，可以用雾带（青竹山、雷泽谷）或熔岩逆光（玄岩洞）。暗色地图给剪影加 4–6px 柔光描边，颜色取该地图的点缀色，在 Godot 里用 shader 实现。

## 4. 角色剪影规则

- 主角面朝右，敌人面朝左（引擎内用 `flip_h`）。脚底对齐帧底部的锚点。
- 游戏内尺寸参考（1280×720）：主角身高约 150–165px，狼妖身长约 180px，岩傀（精英/首领原型）身高约 220–270px。
- 攻击帧要拉开负空间，武器和四肢不要与躯干完全重叠。受击帧身体后仰，四肢前甩。
- 披帛和发带是主角的「速度表」：待机时下垂，攻击时向后拉直，受击时向前甩。做动画时作为次级动作跟随 1–2 帧。

## 5. 后续资源规格建议（供前端参考）

### 5.1 角色动作图集

基准为 1x，对应 1280×720。源文件建议按 2x 绘制，导出 1x 进游戏；如以后要支持 1080p 以上，可再导出 2x 版本。

| 对象 | 单帧尺寸 | 锚点（脚底，相对帧左上） | 动作：帧数 @ 帧率 |
| --- | --- | --- | --- |
| 主角 | 320×192 | (144, 184) | 待机 8f@10fps 循环；行走 8f@12fps 循环；普攻 6f@15fps（第 3 帧为命中帧）；施法 6f@12fps；闪避 5f@16fps（约 0.3s，对应免伤时长）；受击 3f@12fps；死亡 8f@10fps |
| 普通怪（狼妖等 6 种） | 256×160（人形怪 192×192） | (128, 152) | 待机 6f@8fps；移动 6f@12fps；攻击 6f@12fps；受击 3f@12fps；死亡 6f@10fps |
| 首领（3 种） | 320×320 | (160, 308) | 待机 6f@8fps；移动 8f@10fps；普攻 8f@12fps；危险技能＝前摇 4f（定格到 0.8s 预警结束）+ 出手 4f；受击 3f；死亡 8f@8fps |

- 图集组织：**每个动作一条横向条带**，例如 `chr_hero_attack_06f.png` 为 6×320=1920×192，单张不超过 2048px。在 Godot 中用 SpriteFrames 的「从精灵表添加帧」按网格切帧。
- 剪影 + 一个强调色通道：建议把披帛、发光眼单独导出成叠加层（`*_fx.png`），方便在不同地图中改色（例如 `modulate`），也方便给发光部分加 Add 混合。

### 5.2 背景（视差）

| 层 | 尺寸 | 说明 |
| --- | --- | --- |
| 远景（天空 + 远山） | 1280×720 | 视差 0.1–0.2，可不循环 |
| 中景（山 / 竹 / 雷峰 / 石笋） | 2560×720，左右无缝 | 视差 0.4–0.6 |
| 近景地面 | 2560×160，左右无缝 | 视差 1.0，地平线 y=585 |
| 前景遮挡（竹竿、芦苇、岩壁） | 单件 PNG | 视差 1.2–1.4，放在角色层之上，不要遮挡战斗带 |
| 动态元素 | 序列帧或 shader | 落雷闪光、熔岩流动（UV 滚动 shader）、雾带缓移 |

### 5.3 特效

- 飞剑：剑体 96×24 单图，拖尾用 `Line2D` 加渐变纹理（或拖尾序列 8f），命中剑气弧 6f，单帧 192×192。
- 雷电：建议程序化实现，用 `Line2D` 做折线中点位移，每 2–3 帧重算一次；配一张光晕纹理 64×64，再加命中爆闪 6f（128×128）。
- 护盾：椭圆罩 256×256 单图，配菲涅尔 shader；八卦符文环 256×256 单图（`rotation` 缓转）；受击闪光 4f。
- 掉落光柱：只做一张**灰白通用**竖向渐变纹理（64×512）和一张粒子图（16×16），按品质 `modulate` 着色。高度和宽度由代码控制：白 0、绿 110、蓝 200、紫 300、橙 420（px）；橙装额外加放射光贴图 256×128。
- 发光层统一用 `CanvasItemMaterial.blend_mode = Add`；在浅色背景（青竹山）上加一层 Mix 混合的主色底，避免加色后发白、看不见。

### 5.4 UI

- 面板用九宫格：`NinePatchRect`，源图 64×64，边距 16。按钮和技能格单独切图。
- 技能图标 64×64（源图 128×128）；品质框 72×72，按五种品质各一张，或一张白框加 `modulate`。
- 字体：标题用 Noto Serif SC Bold，数值和正文用 Noto Sans SC（均为 OFL 许可，可随包分发）。打包时建议子集化，或使用 Godot 的 MSDF 字体以支持缩放。伤害数字加 2–3px 深色描边。
- 项目设置：`display/window/stretch/mode = canvas_items`，`aspect = expand`，基准 1280×720。

### 5.5 格式与 Godot 导入

| 资源 | 交付格式 | Godot 导入（Compress Mode） | 其他 |
| --- | --- | --- | --- |
| 角色 / 特效 / UI | PNG-32（RGBA） | Lossless | Mipmaps 关；Fix Alpha Border 开；Filter 线性 |
| 大背景（2560 宽） | PNG 源文件（仓库可另存 WebP q90 以减小体积） | VRAM Compressed（桌面端 S3TC/BPTC），如出现色带改用 Lossy 0.9 | Repeat：无缝层开 |
| 噪声 / 渐变 / 光柱纹理 | PNG 灰度 | Lossless | 用 modulate 着色 |

- 默认纹理过滤：Project Settings → Rendering → Textures → Default Texture Filter 设为 **Linear**（水墨风，不是像素风）。
- 本作首版只做 Windows 桌面端，不做 Web 导出，所以交付以 PNG 为主；WebP 只用来压缩仓库体积，不是必需。

### 5.6 命名规范

`{类别}_{对象}_{动作或部件}[_{变体}]_{帧数}f.png`，全部小写拼音或英文，用下划线分隔：

- 角色：`chr_hero_idle_08f.png`、`chr_hero_attack_06f.png`、`chr_hero_attack_06f_fx.png`
- 敌人和首领：`enm_wolf_run_06f.png`、`boss_golem_skill_08f.png`
- 背景：`bg_qingzhu_far.png`、`bg_leize_mid.png`、`bg_xuanyan_fg_rock01.png`
- 特效：`fx_sword_slash_06f.png`、`fx_thunder_hit_06f.png`、`fx_shield_ring.png`、`fx_loot_beam.png`
- UI：`ui_panel_9p.png`、`ui_icon_skill_feijian.png`、`ui_frame_quality_blue.png`
- 目录：`res://art/{characters,enemies,bosses,bg/<map>,fx,ui}/`
